    Sign in / switch Claude account

    The bridge runs claude -p as this Linux user, so it uses the Pi's single Claude login. Signing in here changes it for every Claude Code session on this Pi, not only the bridge. The bridge picks up the new login on the very next message — no restart needed.

    1. Open this sign-in link on any device and sign in with the account you want.
    2. Copy the code the page shows afterwards and paste it here:
    Or do it from a terminal on the Pi 
    claude auth login --claudeai   # or --console for API billing
