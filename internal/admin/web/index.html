    Who can instruct the bot

    Everyone ticked below can make Claude read files and run commands on this machine. Tick only people you trust like an administrator. Someone added to the group later is not allowed until you tick them here.
    AllowMemberNumber

    Add the bot's number to the group, then members write @bot your request. The bot answers in the group, quoting the request, so everybody sees the progress. Note that WhatsApp delivers every group message to the bot's account; only mentions from approved members are acted on.

    Discord alerts

    Get a Discord message when the status above changes (e.g. WhatsApp disconnects) and when it recovers. While a problem continues, a reminder repeats every 30 minutes.

    In Discord: channel Settings → Integrations → Webhooks → New Webhook → Copy Webhook URL.

    WhatsApp recovery

    Reconnect is the first thing to try if WhatsApp shows disconnected. To move to a different number, unlink the current one and then pair the new one by QR or code.

    Sign in / switch Claude account

    The bridge runs claude -p as this Linux user, so it uses this machine's single Claude login. Signing in here changes it for every Claude Code session on this machine, not only the bridge. The bridge picks up the new login on the very next message — no restart needed.

    1. Open this sign-in link on any device and sign in with the account you want.
    2. Copy the code the page shows afterwards and paste it here:
    Or do it from a terminal on this machine 
    claude auth login --claudeai   # or --console for API billing
